# 07. 閉包、迭代器、並行 (Closures, Iterators, Concurrency)

在現代軟體開發中，「高階簡潔的程式碼」與「極致的並行效能」往往難以兩全。然而在 Rust 中，我們透過**函數式程式設計（閉包與迭代器）**，以及舉世聞名的 **「無懼並發（Fearless Concurrency）」**，讓這兩者完美並存！

本單元將透過**工廠傳送帶**、**跨部門郵件管道**與**辦公室保險箱**的比喻，帶你輕鬆掌握這些讓高階工程師愛不釋手的強大特性。

---

## 1. ⚡ 概念解析：三大現代程式設計基石

| 核心特性 | 生活比喻 | 解決什麼難題？ | 核心優勢 |
| :--- | :--- | :--- | :--- |
| **閉包 (Closures)** | 🎒 **便攜魔法口袋** | 想要一個能隨身攜帶、還能記住周圍環境變數的匿名函式 | 語法極簡 `\|x\| ...`，自動推導型別 |
| **迭代器 (Iterators)** | 🏭 **工廠傳送帶流水線** | 想要鏈式過濾、加工資料，卻不想寫一堆容易出錯的巢狀迴圈 | **惰性求值**，零成本抽象（編譯後速度與手寫 C 迴圈相同） |
| **無懼並發 (Concurrency)** | 📮 **MPSC 管道 / 🔐 保險箱** | 傳統多執行緒最怕資料競爭（Data Race）與死鎖當機 | **編譯期直接防堵並發 Bug**，不安全就通不過編譯！ |

## 3. 🧩 深度拆解：核心思維與防護機制

### ① 閉包 (Closures)：捕獲周遭環境的匿名函式
閉包不同於一般函式（`fn`），它能「看見」並「抓住」定義它時周圍的變數：
- **借用捕獲 (`Fn`)**：只讀取外部變數，不修改也不銷毀。
- **可變借用捕獲 (`FnMut`)**：允許在閉包內部修改外部變數的內容。
- **所有權轉移捕獲 (`FnOnce` / `move`)**：加上 `move` 關鍵字後，外部變數的所有權直接搬移進閉包！這在**跨執行緒 `thread::spawn(move || ...)`** 時至關重要，因為子執行緒必須擁有資料的所有權，才不會在主執行緒結束後存取到懸空記憶體！

### ② 迭代器 (Iterators)：傳送帶上的惰性求值 (Lazy Evaluation)
在 Rust 中，建立迭代器不會消耗任何效能：
- **惰性特性**：當你寫出 `v.iter().map(|x| x * 2)` 時，傳送帶**完全不會開始轉動**，它只是一張配方表！
- **啟動開關**：只有當你呼叫了消費型配接器（例如 `.collect()` 收集成向量，或 `.sum()` 計算總和）時，整條流水線才會一口氣高速運轉。這讓編譯器有機會將所有步驟融合成單一迴圈，達到最極致的機器碼優化！

### ③ 無懼並發：Rust 如何杜絕多執行緒當機？
傳統語言在寫多執行緒時常常如履薄冰，但 Rust 依靠所有權系統與型別系統，將資料競爭徹底拒於門外：
1. **訊息傳遞 (Message Passing - MPSC)**：
   - 「不要透過共享記憶體來通訊，而要**透過通訊來共享記憶體**。」
   - 發送端 `tx.send(val)` 一旦執行，變數 `val` 的所有權立刻轉移到接收端 `rx`，原本的執行緒再也無法讀取，根本不可能發生兩人同時修改同一塊記憶體的意外！
2. **共享狀態並發 (Shared State Concurrency)**：
   - **`Mutex<T>` (互斥鎖)**：像保險箱，同一時間只允許一個執行緒呼叫 `.lock()` 取得存取權。
   - **`Arc<T>` (原子參照計數)**：像能安全跨執行緒分發的多把備份鑰匙。
   - 兩者結合：`Arc<Mutex<T>>`，是跨執行緒共享可變資料的黃金標準！

### 範例一：閉包 (Closure) 環境捕獲與 move 關鍵字
- **核心觀念**：

  - 使用 `move` 強制將變數所有權搬入閉包，確保安全獨立。

## 5. 💡 本章核心重點速記

1. **閉包** 是能隨身捕獲環境變數的便攜函式，搭配 `move` 確保跨執行緒時擁有獨立所有權。
2. **迭代器是惰性的**，直到呼叫 `.collect()` 或 `.sum()` 等消費方法才會真正運算。
3. **MPSC 通道** 透過所有權轉移實現跨執行緒無痛通訊。
4. **`Arc<Mutex<T>>`** 是安全共享可變記憶體的防護罩，編譯器在編譯期就已為你排除所有 Data Race！
